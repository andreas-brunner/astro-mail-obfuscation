# Security

Only the latest version of `astro-mail-obfuscation` is supported.

Please use [GitHub's private vulnerability reporting](https://github.com/andreas-brunner/astro-mail-obfuscation/security/advisories/new) to report security issues.

For non-security issues, please use [GitHub Issues](https://github.com/andreas-brunner/astro-mail-obfuscation/issues/new).
